# cafe-landing

가상의 카페 "모닝빈"을 위한 간단한 랜딩 페이지입니다. 빌드 도구 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (반응형 레이아웃, 카페 느낌의 갈색 톤) |

## 실행 방법

`index.html` 파일을 브라우저로 열면 바로 확인할 수 있습니다.

## 수정 방법

- 카페 이름, 메뉴, 가격, 주소, 영업시간은 `index.html`에 들어 있는 예시 내용입니다. 실제 정보로 바꿔서 사용하세요.
- 색상과 글꼴은 `style.css`에서 바꿀 수 있습니다.
